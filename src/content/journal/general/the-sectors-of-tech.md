# The Four Sectors of Technology



## Software development 

Software development is the start of every application, software, or any technical development out there. This includes all of our applications and the code running behind it. All of that is encompassed when you’re thinking about software development. It's the basics of everything technology because everything typically runs on this. You won’t have any of the other categories I’m going to mention without someone putting the code to make a function run and putting the interface on it so that users can use it, and not have to worry about things like the command line or any of the complex components that goes on behind it.

## Data management 

Data management pairs up well with software development because behind software development is the data that goes behind it. Every application needs a database to pull its information from and put its information in properly to have this information lined up, organized and sorted in a way that can be pulled, retrieved, and in a reasonable manner. Not only that, we confirm metrics with policy and data integrity. We need proper management of data and deep understanding of back up and recovery to verify that at the end of the day, the information we have is true and works.

## Networking 

Networking is the start of the second half of technology. Essentially when you have your application, you have the information behind it. You wanna make sure that you can connect to others so when you’re not physically at this location or if you are in and connected physically, you have it to where it’s able to communicate. With these networks, you want to ensure that people are able to access information in the smooth and fast manner and a faster reliability so that essentially it’s easier than sending it in by physical mail or repronounce such information. We can send these devices over but when we have a proper network in place we truly have a worldwide Web of connections. We’ll truly have a network for whatever we’re building.


## Cyber Security 

Cyber security is the start of the true enforcement of everything technology. So once you have your application, you have the database with the information on it. You have the network since everyone’s access to it. You have to know of security protocols because you may not want everyone to have access to this information or certain aspects of it.  You wanna ensure that bad actors do not get in and do not have access to violate the integrity of the data. We have to comprise the function of what you’re building or what you have in the system you have in place.
